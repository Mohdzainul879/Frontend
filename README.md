# Campus Food Intelligence System

An AI-powered Food Waste Prevention and Mess Optimization System for hostels and college mess facilities.

## Features

- Student meal booking and tracking
- Accountability scoring system
- Admin predictive analytics dashboard
- Menu management
- Sustainability metrics

## Tech Stack

- ReactJS + Vite
- Tailwind CSS
- React Router v6
- Context API
- Recharts
- React Icons

## Setup

1. Clone the repository
2. `cd Campus-Food-Intelligence-System`
3. `npm install`
4. `npm run dev`
5. Open http://localhost:5173 in your browser
